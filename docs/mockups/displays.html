Dialog displays: everything a dialog can show

Static mock-up. Besides text and options, the game's dialog has a visual panel (left: a person, several people, an illustration, a planet, fleets, a map marker) and can put displays inside the text: gained or lost cargo, credits, ships and officers, reputation changes, costs, images, skill panels. A Dialog node lists its displays in order, and the preview draws them as the game does.

What can be shown, and how it's exported

From the game's VisualPanelAPI, TextPanelAPI, TooltipMakerAPI and the rule commands in impl.campaign.rulecmd (0.98a). Vanilla commands are used wherever they exist; the rest come from SagaLib.

Lists of commands and their parameters live in the definitions data file (Q11), so a new game version is a data update. The preview draws every row; anything it can't draw exactly is shown as a labelled placeholder of the right size.
