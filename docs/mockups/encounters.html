Encounters: a quest ambush fleet

Static mock-up. An encounter is a fleet (or an interaction with a custom entity) with a place, a trigger, a behavior and outcomes. Encounters used by a quest are spawned on a quest stage, the way vanilla quests do (triggerCreateFleet); standalone ones are spawned by SagaLib's fleet manager. The comm-link dialog uses the same chart editor as quests.
