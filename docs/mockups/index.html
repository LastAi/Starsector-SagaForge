Saga Forge: screen mock-ups

Static mock-ups of the main pages, styled like Ship Editor (same colors, header, toolbars, panels). They follow one example mod, Vanguard Compact (id prefix vgc_): a new faction, a change to the Hegemony, a new star system with a station and a contact, and a quest with a branching conversation and an ambush fleet. The walkthrough and the pitch are in PITCH.md; the full design is in PLAN.md. Vanilla names and ids are real (0.98a); all art is placeholder.
