Test profiles: start with flags already set

A test profile is a saved game situation: quest steps, flags, variables, reputation, commission, credits, cargo. The same profile drives the editor's Play mode and, through SagaLib in the game's dev mode, a real game: applied when a new game starts, or at any time from SagaLib's dev menu, with the quest JSON reloaded from disk without restarting.

Use it in game SagaLib dev mode

  1. Turn on the game's devMode in settings.json (your own step; Saga Forge never edits the game).
  2. New game: after the sector is made, SagaLib asks which profile to apply (or none).
  3. Any time: SagaLib's dev menu (hotkey, dev mode only) lists the profiles, applies one, or reloads the mod's JSON so text and step changes show without restarting.
