Quest planner: Plan mode

Static mock-up of the heart of the tool. The quest The Lost Convoy is planned as a flow chart. Each Dialog node is one rules.csv row: text plus its options, one output handle per option. Stage frames group the nodes of a journal stage. The bottom panel draws the selected node the way the game's dialog window does, with tokens filled in from the Test context.

One node = one rule. A Dialog node holds the text and the options of one rules.csv row, so the chart reads like the conversation. Option ids are made from the quest id and the option text (vgc_lost_convoy_accept).
Stage frames. Nodes inside a stage frame belong to that journal stage. A Stage node moves the quest there (SF_Step), updating the journal text and map markers.
Problems on the chart. Red corner: "Avoided leads nowhere". Yellow corner: "the convoy wreck only exists in new games" (see Export & save warnings).
Links into vanilla. Dashed nodes are read-only rules from the game or other mods. "Not interested" goes back to the contact's vanilla menu; nothing of vanilla's is changed.

Quest planner: Play mode

Play ▶ runs the exported rules (not the chart) with a small copy of the game's rules engine and SagaLib's logic. Click options in the preview; the chart shows the path taken, the log explains each choice, variables update live. Things it can't simulate, like a fleet battle, ask you for the outcome.
