Items: quest items and other new cargo

Static mock-up. Items the mod adds: commodities (rows in commodities.csv, like the convoy's black box) and special items (rows in special_items.csv, using vanilla's generic item plugin, so no code). Each has its description: commodities in descriptions.csv (type RESOURCE), special items in the desc column of their own row. Existing items are listed read-only: a row with the same id would replace vanilla's whole row, so the editor never writes one.

Special items
