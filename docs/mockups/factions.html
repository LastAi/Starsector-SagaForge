Factions: changing an existing faction (override)

Selecting "Hegemony" under Changes to other factions. The editor shows the effective faction: vanilla's values, other installed mods' changes (greyed, with the mod's name), and this mod's changes (orange). It only ever saves this mod's patch, at the same path as vanilla's file, so the game merges it.
